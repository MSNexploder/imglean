# Security Policy

## Supported versions

Before the first public release, security fixes are applied to the current
`main` branch. After publication, only the latest released ImgLean version is
supported.

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting for
ImgLean](https://github.com/MSNexploder/imglean/security/advisories/new).

Do not disclose a suspected vulnerability in a public issue. Include the
affected version or commit, the operating system, reproduction steps, and the
expected impact when available.

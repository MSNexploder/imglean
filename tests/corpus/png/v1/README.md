# Version 0.1 PNG Corpus

This bounded corpus is generated by `tools/generate_png_corpus.py` and committed
as binary PNG fixtures. It covers every accepted color-type/bit-depth pair,
palette transparency, accepted ancillary families and placement, fully
transparent nonzero color samples, filter/DEFLATE/IDAT equivalence, semantic
change, malformed and truncated structure, APNG, XMP, `caBX`, unknown chunks,
trailing data, limit rejection, and a guaranteed OxiPNG reduction.

The validator test enumerates every file explicitly so an added or removed
fixture requires a reviewed expectation change.
